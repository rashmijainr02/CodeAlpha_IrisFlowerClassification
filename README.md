# Iris Flower Classification

This project uses machine learning to classify Iris flowers into 3 species 
(Setosa, Versicolor, Virginica) based on their petal and sepal measurements.

## Tools Used
- Python
- Scikit-learn
- Pandas

## How it works
1. Loaded the Iris dataset
2. Split data into training and testing sets
3. Trained a Decision Tree Classifier
4. Achieved 100% accuracy on test data
